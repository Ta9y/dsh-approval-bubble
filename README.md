# dsh-approval-bubble

整个插件，除了这一行字以外，由DeepSeek Harness生成

一个 DSH（DeepSeek Harness）桌面端插件：当**后台会话**出现待交互请求（权限审批、选项提问、计划确认）时，在侧栏对应会话行右侧弹出一张气泡卡片，就地完成交互，不必切换会话。

> English README: [README.en.md](./README.en.md)
>
> GitHub: <https://github.com/Ta9y/dsh-approval-bubble>

## 功能特性

- **权限申请**：显示工具名与申请理由，一键「拒绝 / 允许一次」，支持翻译与复制。
- **选项提问**：单选 / 多选 / 自定义「其他回答…」/ 跳过 / 上一步 / 下一步 / 提交；多题分页、推荐项标记。
- **计划确认**：显示计划标题与摘要，可展开全文、一键通过、打开会话。
- **可拖动**：按住标题栏拖动，松手后位置固定；同一请求结束后，下一个请求回到会话行旁。
- **宽度自适应**：宽度约为窗口宽度的 26%（268–420px 上下限），随窗口缩放实时变化。
- **颜色区分**：橙色 = 权限申请；蓝色 = 普通提问 / 计划确认。
- **兜底位置**：会话行不可见（工作区折叠 / 侧栏收起 / 行滚出视口）时，气泡改为右下角堆叠，避免错过请求。
- **不重复打扰**：主视图会话不弹气泡（由自带输入区接管）。

## ⚠️ 高危权限使用声明（务必阅读）

本插件会直接呈现并**代你提交权限审批结果**，其中「允许一次」是高危操作：

1. **「允许一次」= 授予这一次工具调用的提权执行权**。它可能带来工作区之外的文件写入、命令执行、网络访问等后果；DSH 的 Host 代码在**进程内、工作区沙箱之外**执行，一旦同意无法撤回。
2. **务必先看清工具名与申请理由再决定**。理由文本可能由模型生成，不能作为安全保证；不确定时请选择「拒绝」。
3. 本插件**不会**自动同意、不会绕过、不会降低任何审批策略；每一次授权都必须由你亲自点击按钮完成，且不会新增任何模型可见的工具。
4. 「翻译」会把当前气泡文本（申请理由 / 题干与选项 / 计划摘要）发送到微软 Bing 的匿名翻译端点（Bing 不可用时会回退到 Google 匿名端点）；**不要对含敏感信息的请求点击翻译**。
5. 「复制」会把当前内容写入系统剪贴板；剪贴板可能被其他程序读取，请自行判断内容敏感性。
6. 插件不写会话日志、不上传遥测；Host 侧仅注册一个带同源守卫的本地翻译路由（`/dsh-approval-bubble/translate`），无鉴权口令、仅接受同源或 `dsh-app://app` 来源。

## 环境要求

- DSH 桌面端 `0.2.1-rc.2` 及以上，profile 名 `desktop`；
- profile 已启用 HMR（默认启用）。

## 安装

命令行（Windows，`dsh` 位于 DSH 安装目录的 `runtime\cli\bin`）：

```powershell
dsh plugin --profile desktop add "file:<本仓库绝对路径>"
```

或使用图形界面：**Settings → Plugins → 安装**，选择本仓库文件夹。安装后会把 `dsh-approval-bubble`
加入 profile 的 `dsh.profile.bundles` 并触发热加载；若未生效，重启一次 DSH 即可。

## 使用

1. 把主视图切到**另一个会话**（让目标会话变成后台）；
2. 该后台会话出现审批 / 提问 / 计划确认时，侧栏对应行右侧弹出气泡；
3. 就地点击按钮完成交互；可按住标题栏拖动位置。

## 外观与配色

- 权限申请：`--dsw-alias-state-warn-*`（橙色，浅/深主题均为 `#f59e0b`）；
- 提问 / 计划确认：`--dsw-alias-state-business-primary`（浅色 `#4176e6` / 深色 `#7aaaff`）；
- 注意：本产品主题里的 `--dsw-alias-brand-primary` 是黑白墨色，不是蓝色，勿混用。

## 权限与接口

| 方向 | 接口 / 数据 | 用途 | 频率 |
| --- | --- | --- | --- |
| 读取（客户端） | `uiSession.sessionStatus`（Map） | 发现待交互请求、判断是否可回答 | 状态变化事件 + 约 100ms 布局循环 |
| 读取（客户端） | `sessions.list` | 会话标题、是否在主视图 | 同上 |
| 读取（客户端） | `locale` 服务 | 中/英文案切换 | 语言变化事件 |
| 写入（本机） | `POST /dsh-approval-bubble/translate` | 翻译气泡文本 | 用户点击「翻译」时 |
| 探针（本机） | `GET/POST /dsh-approval-bubble/ping` | 自检：页面加载 / 槽位挂载 / 气泡计数 | 页面加载与布局变化时 |
| 出网 | Bing Edge 匿名翻译端点（不可用时回退 Google） | 机器翻译 | 每次点击「翻译」一次 |

- 不注册模型工具、不监听会话事件、不写会话日志、不读写工作区文件；
- 两条本地路由都包在 `ctx.effect` 中，插件卸载 / 热重载时自动注销。

## 隐私

- 气泡只读取会话状态（`uiSession.sessionStatus`）与会话标题，不读取对话正文；
- 翻译是点击触发的显式操作，文本仅发往 Bing 匿名端点（不可用时回退 Google），不经过任何自建服务器；
- 无遥测、无日志文件、无本地存储。

## 已知限制

- 主视图会话不弹气泡（自带 composer 接管）；
- 同一会话只呈现系统判定的最高优先级请求；
- 行不可见时使用右下角兜底位置，不精确对齐会话行；
- 无浏览器自动化能力，视觉与点击验证以真机为准。

## 卸载

```powershell
dsh plugin --profile desktop remove dsh-approval-bubble
```
